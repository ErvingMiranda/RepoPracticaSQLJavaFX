## Descripción
Aplicación de escritorio desarrollada con JavaFX y PostgreSQL para registrar y consultar información de empleados. Permite ingresar los datos desde un formulario, almacenarlos en la base de datos `biblioteca_fx` mediante JDBC y mostrar los registros en un TableView. También permite ejecutar distintas consultas para visualizar y filtrar la información almacenada.
